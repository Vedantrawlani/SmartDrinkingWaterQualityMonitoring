# Smart Drinking Water Quality Monitoring System
### IoT-Based Water Quality Monitoring for Residential Communities

---

> [!IMPORTANT]
> **DEMO MODE NOTICE**  
> **Current Version:** Interactive software demonstration using simulated sensor data. No physical sensors or ESP32 hardware are connected in this release. All telemetry is generated by an internal simulation engine to demonstrate the dashboard architecture, parameter grading, and alert management workflows.

---

## 1. Overview

The **Smart Drinking Water Quality Monitoring System** is an accessible, IoT-enabled continuous surveillance dashboard tailored for residential communities and water storage facilities. The system monitors water quality across multiple tanks, evaluates readings against standard thresholds, and displays real-time status indicators, historical analytics, and actionable alerts.

---

## 2. Monitored Parameters & Standards Reference

The dashboard monitors four primary water quality indicators evaluated against standard drinking water baselines (such as BIS IS 10500:2012):

| Parameter | Unit | Acceptable Demonstration Range | Standard Baseline | Description |
| :--- | :--- | :--- | :--- | :--- |
| **pH Level** | Unitless | `6.5 – 8.5` | `6.5 – 8.5` | Measures hydrogen-ion concentration. Values outside 6.5–8.5 indicate acidic or alkaline tendencies. |
| **Total Dissolved Solids (TDS)** | `mg/L` | `<= 500 mg/L` | Acceptable: `500 mg/L` | Measures dissolved inorganic minerals and salts. Elevated TDS affects taste and hardness. |
| **Turbidity** | `NTU` | `<= 1.0 NTU` | Acceptable: `1.0 NTU` | Measures optical clarity. High turbidity indicates suspended particulates requiring filtration check. |
| **Water Temperature** | `°C` | `15.0 – 32.0 °C` | Cool ambient storage | Monitors ambient water storage temperature stability. |

## 3. End-to-End System Architecture

The complete system pipeline is designed to transition seamlessly from simulated telemetry to physical IoT sensors:

```
[ Water-Quality Sensors ] (pH Probe, TDS Electrodes, Turbidity Sensor, DS18B20 Temp)
            │
            ▼
[ ESP32 Microcontroller Node ] (ADS1115 16-bit ADC, Local Calibration, JSON Serialization)
            │
            ▼
[ Wi-Fi / Cellular Telemetry ] (MQTT over TLS / HTTPS REST Ingestion)
            │
            ▼
[ Processing Layer ] (Data Validation, Time-Series Storage, Rule Engine)
            │
            ▼
[ Web Dashboard (Streamlit) ] (Real-time Visuals, Plotly Trends, Multi-Tank Telemetry)
            │
            ▼
[ Threshold-Based Alerts ] (Categorical Severity, In-Dashboard Notifications)
            │
            ▼
[ Inspection & Corrective Action ] (Source Isolation, Filter Backwash, Confirmatory Lab Test)
```

## 4. Key Dashboard Sections

The dashboard consists of five core views accessible via the sidebar navigation:

1. **📊 Overview Dashboard**:
   - Live telemetry status ribbon.
   - Primary metric cards for pH, TDS, Turbidity, and Temperature with status indicators (`Normal`, `Warning`, or `Requires Inspection`).
   - Water Quality Index gauge (0–100 composite score).
   - Recent open alerts summary.
   - Monitored tanks status table.

2. **📡 Live Monitoring**:
   - Dropdown to select and monitor specific water tanks.
   - Manual **"Generate New Reading"** button.
   - **"Inject Simulated Spike"** tool to test alert triggers on demand.
   - Recent telemetry records table with **CSV export**.

3. **📈 Historical Analytics**:
   - Interactive Plotly time-series charts with dashed threshold reference lines.
   - Individual parameter tabs and synchronized multi-trend view.
   - Configurable time windows (*Last 1 Hour*, *Last 6 Hours*, *Last 24 Hours*, *All Records*).
   - Computed summary statistics: Average, Minimum, Maximum, Total Records, and Exceedance Counts.

4. **🔔 Alerts & Notifications**:
   - Automated threshold-driven alerts with unique Alert IDs.
   - Lifecycle actions: `Acknowledge` and `Mark Resolved`.
   - Contextual remedial guidance for every breach.

5. **🚰 Water Tanks**:
   - Profiles for monitored residential storage units.
   - Live sensor readings, sample timestamps, open alert counts, and status indicators.

6. **⚙️ Threshold Configuration (Sidebar Expander)**:
   - Dynamic threshold adjustments for Min/Max pH, Max TDS, Max Turbidity, and Min/Max Temperature.
   - One-click reset to standard baseline defaults.
